## 固定系统提示词

system仅保留固定英文身份、版本与通用规则，同一Brain首次构建后复用完全相同文本。目标、当前窗口、按需命令目录、执行历史和收到的游戏聊天均放入user消息；中文任务／分类不会进入system。窗口变化仍更新当前可调用命令与解析白名单，不为缓存而开放隐藏接口。不同版本／代码的system可能不同；固定文本有利于供应商前缀缓存，但不保证命中，不将缓存字符数当作命中token或费用。

本轮调整需重启后台加载，已有历史输入保留原文；新增测试核对中文目标、窗口及历史变化时system逐字符一致且无中文。本轮未修改运行间隔、没有添加文字回复命令，仍使用游戏say。

- **One step（默认）**：新任务替换运行时goal，清除旧任务执行历史；调用一次模型，并最多执行其选中的一个命令，展示实际API结果后停止。不表示整个自然语言任务已完成。
- **Continuous**：明确启动自主循环，按该角色配置间隔继续调用，直到Stop／断线等生命周期结束；不会根据DONE文本自动判断任务完成，会持续产生模型费用。
- **Stop**：取消该角色Brain及其动作，晚到模型回复不会继续执行。已经发生的世界变化无法撤销；取消不保证供应商不计费。
- 每次任务最长4000字符；离线／缺Key拒绝。运行中或旧请求尚未结束时拒绝替换（409），不暗中追加并发任务。等待时禁用Send，失败保留输入；成功后展开该角色输入输出，显示选中命令与实际API返回。`confirmed`含义不变，不把发出请求当作效果成功。
- 任务只存在本次后台进程，不写入配置。不同agent的goal、历史、执行与诊断记录分开。文本和结果用纯文本渲染。

接口：`POST /api/agents/:name/planner/message`，JSON `{"message":"查询我的背包","mode":"once"}`。mode省略默认为once；continuous是另一合法值。单步等待模型／执行结束返回，持续模式返回started。关闭页面不自动取消后台任务，停止需明确使用Stop。

自动回归464/464；单步一次、输入校验、缺Key／离线、并发拒绝、晚到回复取消、显式持续模式、错误脱敏、实际命令失败反馈、HTTP角色隔离均覆盖。浏览器夹具使用明确标识的本地模拟模型，不冒充真实DeepSeek。

用户重启后的真实8090后台实测一次DeepSeek：系统首行为 `You are SteveX, a Minecraft agent using Mineflayer. Minecraft Java Edition 1.21.11.`，返回inventory，耗时1010ms，随后停止。另在用户加载新任务路由后，以once模式提交“你好”，真实模型返回 `say 你好`，HTTP200并调用实际游戏say接口，随后停止。返回confirmed=false，仅证明发送请求，不冒称服务端交付。

此前测试角色只开放pos／inventory／hp，导致模型返回say却被白名单拒绝；本地测试配置已移除该临时限制，使用完整默认游戏命令目录，仍按窗口暴露、仍隐藏管理／创造接口。无Key的测试角色不会借用其他角色的Key。没有增加文字回复命令或问候专用提示词。

注意：当前单步是单条命令，不是完整任务；每次提交会重置旧历史。持续模式使用角色配置间隔，测试配置曾为3600000ms，查询背包后不会立即继续say。这是后续Agent调度／交互改进项，本轮未擅自更改间隔或完成判据。固定英文system调整已通过自动测试，未再次调用付费模型验证缓存命中。
