## 当前接口

- `slotinfo inventory:9`、`slotinfo window:0`：详情只读，固定编号和组件解析不变。
- `slotclick inventory:9 right`、`moveslot inventory:9 window:0 2`、`putaway window:0`：单个槽位引用，拒绝旧分离参数和裸编号。
- `transfer deposit 9 2`、`transfer withdraw 0 1`：方向分别确定inventory/window来源，不再重复scope。
- `drop slot 10 2`：仅所选固定玩家9..44槽，超量拒绝，不跨其他堆补足；省略数量丢整堆。按名drop保留。

## 反馈与同步

Brain历史统一保存JSON结果，保留status、confirmed、hit:null、错误码、候选、下一查询及部分效果；重复查询JSON不再作为文本重复发送。非重复output放入message，不截断结果、不自动追加状态查询。

工作站使用操作前后服务端库存快照，反馈changes、stateChanges、evidence；失败保留已观察的部分变化，最终确认失败为changes:null。不重复整窗物品内容，需要时主动window查询。原生方法ok不能覆盖最终确认失败。炉子按精确所选组件堆搬运，来源减少才确认；附魔选择核对目标组件变化，交易核对产物净增。重复已满足的合成器设置允许成功且不额外发送设置包。

库存快照默认2000ms上限，支持取消、断线、关窗、窗口替换及重生，清理自有定时器／监听。启动时替换上游craft/book快照入口。用于确认的最终同步独立有界，即使动作取消仍尽量记录部分变化。不会用超时竞争强行释放仍在执行的原生变更操作。
