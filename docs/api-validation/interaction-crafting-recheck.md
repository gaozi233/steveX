## 测试脚本发现的问题

1. 旧合成脚本以 `inventory.inventory` 读取结果，而当前摘要为分组、详细查询为 `inventory slots` 的 `slots`。首项目标实际完成，统计阶段中断；修正读法并添加拒绝旧契约的回归测试，重新执行整组。中断的18次真实调用单独计入，不冒称未付费或整组通过。
2. 恢复朝向仍使用已移除的旧look语法，改为 `look angle` 的Minecraft度数约定。
3. 放置测试紧接挖掘时，同名圆石掉落物被捡起，会抵消背包消耗的净变化。改用橡木木板独立核验，保留失败记录；并等待独立的持物同步包，再核对服务端数量。不把未确认放置盲目重试，也不放宽生产确认条件。
