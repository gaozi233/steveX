# 背包、持续使用与返还物覆盖摘要

整理：2026-10-23。合并背包操作、盾牌、药水／牛奶／弩、满背包返瓶返桶四份重复记录。以下是最近有效实测结论，**不是本轮重新运行**；旧原始日志已清理，不再给出失效 JSON 路径。当前命令及未测项以 [验收清单](../api-acceptance-checklist.md) 为准。

## 当前调用

```text
equip shield off-hand
rightdown off-hand
wait 10
rightup
```

rightdown 默认主手，也可指定 off-hand；只确认使用请求，不保证已经吃完或挡住。移动、转向、跳跃、停步、等待与查询保持使用；rightup、切换物品、互斥交互及安全取消结束使用。rightup 可能松弓射箭，但不会发射已装填弩。短按 rightclick 不代替长按吃喝。

## 有效覆盖

测试为 Minecraft Java 1.21.11 生存角色，经正式 HTTP 命令入口，服务端数据只作验收真值，不开放给 Agent。测试时隔离场地及角色；盾牌测试无盔甲／吸收／抗性，临时 easy，正面伤害等待举盾生效及无敌帧结束。

| 接口／场景 | 最新有效结论 | 仍需注意 |
| --- | --- | --- |
| equip | 精确名不误选近似名称；四件盔甲／副手正确，数量守恒；缺物拒绝 | 不自动选择最优组件 |
| hotbar | 0/8 对照服务端 SelectedItemSlot；空槽与非法值核对 | 高延迟切换待测 |
| unequip | 盔甲／副手回包、空槽重复无损；36 格满包时无损拒绝 | 不可卸装备与并发待测 |
| drop | 丢 3 留 7、地面计数及同名 A/B 组件隔离；不足不部分丢弃 | 默认首堆及跨同组件数量有既有覆盖，不支持指定组件选择 |
| 持续进食 | 面包消耗并恢复饥饿；提前松开不消耗；重复开始不重置 | 不承诺自动连续吃多个 |

| 喷溅药水 | 消耗且无空瓶；靶子实际扣血 | 受距离和落点影响，不宣称固定伤害 |

## 满背包返瓶／返桶（16 组）

药水／牛奶 × 主手／副手 × 普通单件／自定义双件堆叠 × 有／无兼容容器容量，共 16 组；36 格主包／快捷栏始终无空格，服务端库存、掉落与查询结果交叉核对。

| 满包条件 | 药水喝完 | 牛奶喝完 |
| --- | --- | --- |
| 单件，无可合并返还物 | 原持物槽替换为 1 瓶，地面无掉落 | 原持物槽替换为 1 桶，地面无掉落 |
| 单件，已有返还物堆叠 | 原持物槽仍返 1 瓶，其他瓶堆叠不变 | 原持物槽仍返 1 桶，其他桶堆叠不变 |
| 自定义双件，无容器容量 | 原药水剩 1，瓶掉地 1 | 原牛奶剩 1，桶掉地 1 |
| 自定义双件，有兼容容量 | 原药水剩 1，瓶 63→64，无掉落 | 原牛奶剩 1，桶 15→16，无掉落 |

主副手分别核对；单件副手饮完返还物留副手。普通生存药水和牛奶桶不可这样堆叠，自定义双件只代表地图组件边界。空格为 0 不等于无法原槽替换或堆叠。保留 last known 饱和度，不新增服务端同步或自动规划。
