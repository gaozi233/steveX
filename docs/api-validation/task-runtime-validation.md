# 有界任务循环与调度验收

2026-10-23。本轮为运行时基础，不实现 HBT、群体学习、自动规划或滚动摘要。

## 已验证

- 全库自动回归 **481/481**。覆盖任务预算、单步继续、追加消息、取消、超时、连续失败、旧请求晚到、真实动作队列取消与松键、角色隔离、HTTP 控制及错误脱敏。
- 本地 HTTP 模拟验收 3/3：单步继续保留任务 ID／历史／固定 system，持续模式不受旧一小时间隔影响，取消后晚到推理不执行动作且不影响另一角色。
- Edge 8092 模拟页面：第一次查询背包；Continue 使用同任务历史生成 say；手动完成明确标注环境未验证；新任务设置两次调用后自动 budget_exhausted，另一角色仍无任务。
- 每步显示模型耗时、动作排队／执行耗时和供应商实际返回的 usage。未返回 token 时显示不可用，不按字符估算，不当作零费用。

## 边界与待测

- 本轮没有连接 Minecraft、没有付费 DeepSeek 调用；模拟成功不是游戏任务成功率，也不是性能基准。
- 保留最近 10 条执行历史，未实施摘要／长期上下文管理。重复查询只计数，不自动判定无进展。
- completed 是人工声明，不是环境判定；say DONE 不会自动结束任务。真实长程任务完成判据待后续设计。
- 取消阻止晚到命令并请求动作取消；不撤销世界变化，不保证供应商停止计费。旧动作实际结算前不启动新任务。
- 暂停时间仍计入任务墙钟截止时间。追加消息不重置预算；推理期间追加会丢弃旧决策，执行中追加则等待当前动作结束后使用。
- 固定英文 system 保持原文，不新增周期状态快照，不扩张 LLM 命令权限。
