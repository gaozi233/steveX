## 当前行为

| 接口 | 口径 |
| --- | --- |
| move sprint [durationMs] | 同时按 forward+sprint，默认1000ms、1..30000；到时／取消释放双键，保留既有潜行及持物使用的项目边界。饥饿、碰撞、水中等条件可阻止实际疾跑；载具仍拒绝 |
| goto x y z | 绝对数值或 ~ 偏移；出队时采样脚部坐标，混合解析后向下取整；例如 goto ~3 ~ ~1。不支持 ^；采用既有路径器策略，不等同受保护的 dig/collect 接近 |
| findblock 名称或#标签 [radius] [count] | radius默认32、1..128；count默认1、1..16。blocks 返回实际名称／坐标／distance／properties，最近优先；count=1 保留原顶层字段。床头尾不合并，不替模型选用途；count是上限，不是世界匹配总数。tags/tag 子命令不接受 count |
| fish | 仍为无参技能，复用当前 Mineflayer 钓鱼插件的咬钩识别。在私有事件桥运行，只接收本玩家浮漂归属包；不调用无法取消的全局 bot.fish()。默认会话30s，另受外部动作超时／取消约束 |

## 钓鱼生命周期

当前上游没有公开取消钓鱼任务的 API。项目适配层位于 src/commands/fishing_session.js：复用 node_modules/mineflayer/lib/plugins/fishing，不修改依赖文件，也不自行增加新的咬钩推理规则。

- 正常：单次抛竿，检测自己浮漂附近的上游咬钩信号，单次收竿请求；ok 不证明捕获或库存增加，catchConfirmed=false。
- 取消／超时：立即停止向上游会话转发事件；仅已观测自己浮漂且手中仍为原槽钓竿时尝试收竿，不盲目右键造成新抛竿。
- 在途生成最多等待约500ms，收竿后移除确认最多约500ms；清理阶段不重复服从已取消信号，保证释放前有一次有界清理机会。
- 无生成／无移除回执：cleanup 明确未确认；不声称已经清理游戏世界，下一步先观察。
- 断线不向失效连接发收竿；换槽／换物后不使用新物品。清除私有桥、真实监听及计时器，后续粒子不能触发迟到收竿，不阻塞后继队列。
- 反馈包含 castSent/reelRequested/bobberId/cleanup；取消的正式 Agent 调用仍保留可得的清理反馈。底层模块为上游内部接口，更新依赖后须重跑回归；当前游戏验证为 Java 1.21.11。
