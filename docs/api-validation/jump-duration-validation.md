# 持续空格验收

2026-10-23，Minecraft Java 1.21.11 本地专用测试服务端，独立 Jump-Test 生存玩家；调用生产 jump handler，不冒充网页／Brain 库链路测试。未调用模型，未操作人工客户端，不抢鼠标焦点。

## 接口

`jump [durationMs]`，默认 200ms，严格整数 1..30000。时长指保持空格的墙钟毫秒，不是跳跃、上浮或滑翔完成时间。仅首次按下检查并尝试展开鞘翅；保持期间不再次判断、自动发烟花或自动松键等待落地。到时或取消必须松开。

## 实机结果：3/3

| 场景 | 结果 |
| --- | --- |
| 水底保持 2500ms | Y 从 100.0 上升到 105.2，前后服务端 Pos 独立核对一致，到时 jump=false |
| 地面保持 3500ms | 轨迹多次离地超过 0.4 格再回落到地面附近，确认落地后继续起跳；到时即松开，不等待落地，服务端终点仍可能在空中 |
| 保持 30000ms 后主动取消 | 150ms 后取消，返回取消结果并清理 jump 键 |

本地新终记录：`runs/api-acceptance-server/jump-duration-1792737309015.json`；脚本同目录 jump-duration-live.cjs，均忽略提交。首次测试区块未加载，夹具无效；增加强制区块加载和客户端等待后完整重跑，不计首次为通过。结束清除测试平台、水池和强制加载，测试角色断开。

轨迹来自客户端 physicsTick，水中起终点和地面终点另查服务端 Pos，不是同 tick 原版玩家配对实验；不据此宣称精确物理或跳跃频率一致。未覆盖复杂水流、低 TPS、死亡／断线、滑翔实机及烟花组合。

库库自动回归 355/355；新增时长非法输入无副作用、默认短按、保持中落地不重复展翅、到时松键与取消清理覆盖。没有新增自动规划或自动飞行技能。
